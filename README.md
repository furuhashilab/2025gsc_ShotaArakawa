# 2025gsc_ShotaArakawa
2025ゼミ論
## 概要

本研究では、埼玉県行田市を対象に、観光情報を視覚的かつ直感的に理解できるWebマップの構築を行った。HTML・CSS・JavaScriptおよびMapLibre GL JSを用い、観光施設、飲食店、駅、温泉などのスポットをカテゴリ別に色分けして可視化するとともに、写真や外部リンクに加えて動画コンテンツを組み合わせた情報提示を行っている。各スポットのポップアップ内では、現地の雰囲気や魅力を伝えるYouTube動画やショート動画を再生可能とし、地図情報だけでは伝えにくい体験的要素を補完した。さらに、行田市の行政境界をGeoJSONで重ね合わせ、対象地域を明確化するとともに、現在地から目的地までの移動はGoogle Mapsと連携することで、観光情報の閲覧から実際の行動までを自然につなぐ導線設計を実現した。本研究は、動画とWeb GISを統合した観光情報可視化の実践例である。

## I. Introduction（研究背景・目的）

近年、観光情報の取得にはWeb地図やSNS、動画配信サービスが広く利用されている。しかし、地図サービスは位置情報の把握に優れる一方で、現地の雰囲気や体験価値を伝える点では限界がある。一方、動画コンテンツは臨場感に優れるが、位置関係や周遊のイメージを把握しにくいという課題がある。  
本研究では、これらの特性を踏まえ、地図と動画を組み合わせたWebマップを構築し、観光地の魅力を空間的・体験的に伝えることを目的とする。対象地域は埼玉県行田市とし、観光情報の可視化と観光行動を支援する導線設計を検討する。

## II. Methods（手法）

本研究では、HTML・CSS・JavaScriptを用いてWebマップを構築し、MapLibre GL JSおよびOpenStreetMapの地図データを利用した。  
観光施設、飲食店、駅、温泉などのスポット情報を収集し、カテゴリごとに色分けしたピンとして地図上に配置した。各スポットにはポップアップを設定し、名称、説明文、写真、公式サイトへのリンクに加えて、YouTube動画やショート動画を条件付きで表示する仕組みを実装した。  
また、行田市の行政境界をGeoJSON形式で重ね合わせることで対象範囲を明確化した。現在地から目的地までの移動については、ブラウザの位置情報機能とGoogle Mapsのルート表示機能を連携させ、実際の移動行動に即した導線を提供し、観光情報取得だけではなく、実際に訪れる際にも使用できる形にした。

## III. Results（結果）

構築したWebマップにより、行田市内の観光スポットや飲食店、駅などを一画面で把握できるようになった。  
特に、ポップアップ内に動画を組み込むことで、地図上の位置情報と現地の雰囲気や体験イメージを同時に提示することが可能となった。また、カテゴリ別のピン色分けと凡例表示により、初見の利用者でも情報の種類を直感的に理解できるUIを実現した。  
Google Mapsと連携した経路案内機能により、観光情報の閲覧から実際の移動までをスムーズにつなぐことができた。

## IV. Discussion（考察）

本研究のWebマップは、従来の地図サービスが担うナビゲーション機能を補完する形で、観光情報の整理と魅力の提示に特化している点に特徴がある。  
動画コンテンツを組み込むことで、写真やテキストのみでは伝えにくい「現地の空気感」や「体験のイメージ」を補完でき、観光地への関心喚起に有効であると考えられる。一方で、動画の内容や更新頻度によって情報の鮮度が左右されるため、継続的な運用が課題として挙げられる。
また、市役所職員との会話から、非公的な立場により作成される地図の可能性を考えた。市役所という、公的機関が発表する際には様々な懸念点が発生する。飲食店においては、その地図に掲載されるか否かが集客に大きく影響する。そのため、「観光マップ」を作成する際は飲食店との関係値が影響することもあると伺った。公的なものではない観光マップを作成することで、よりユーザー・観光客目線に立った地図を作成することが可能だと考える。

## V. Conclusion（結論）

本研究では、行田市を対象に、動画とWeb GISを組み合わせた観光Webマップを構築した。  
地図による空間的理解と動画による体験的理解を統合することで、観光地の魅力を多角的に伝える手法を示した。さらに、Google Mapsとの連携により、情報閲覧から実際の観光行動までを意識した実用的なWebマップを実現した。  
本研究は、動画コンテンツを活用した観光情報可視化の一つの実践例として、他地域への応用可能性を有すると考えられる。
